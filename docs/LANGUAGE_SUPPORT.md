# Language Support

Codex Wise indexes common application languages through the existing tree-sitter based ingestion pipeline.

Current supported families include Python, TypeScript, JavaScript, Go, Rust, Java, C/C++, C#, Kotlin, Ruby, Swift, PHP, Scala, Dart, and Luau.

Run:

```bash
codex-wise init --index-only
codex-wise status
```

Use `codex-wise doctor` if a repository indexes fewer files than expected.
