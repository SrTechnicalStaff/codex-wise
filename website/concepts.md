# Concepts

The apparatus has four parts:

| Part | Purpose |
|---|---|
| Graph | Files, symbols, imports, calls, communities, and centrality |
| Git | churn, ownership, hotspots, co-change pairs |
| Docs | optional generated wiki pages and semantic search |
| Decisions | explicit and discovered rationale linked to code |

Codex consumes this through MCP tools and generated `AGENTS.md`.
